# ☕ Coffee Shop Website

A modern and responsive coffee shop landing page built with **Next.js 15** and **Tailwind CSS**.
The project provides a clean and attractive user experience with smooth animations, responsive layouts, and modern UI components.

# ✨ Features

* ☕ Modern coffee shop landing page
* 📱 Fully responsive design for all screen sizes
* 🎨 Clean and minimal UI design
* 🚀 Built with Next.js App Router
* ⚡ Fast and optimized performance
* 🎞️ Smooth animations using AOS library
* 📌 Smooth scrolling navigation
* 🛒 Shopping cart icon UI
* 🎁 Gift voucher button
* ☕ Coffee showcase sections
* 📖 About coffee shop section
* 📦 Order coffee section
* ⭐ Customer testimonials section
* 🌟 Responsive image optimization using Next Image

# 📦 Installation and Setup

## 1. Clone the repository

```bash
git clone https://github.com/ibrahimyasser450/Coffee-Shop-Website.git
```

## 2. Navigate to the project folder

```bash
cd coffee_shop
```

## 3. Install dependencies

```bash
npm install
```

## 4. Run the development server

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
